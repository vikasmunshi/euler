{# The section strip — Solutions · Docs · Topics · Terminal — as ONE definition, opening every one of the five index pages: the start page (`_home.html`, rendered by both tiers), solutions, docs, topics and the terminal page. One place to add a fifth section, and five pages that grow it. It is the same tile object the content grids below it wear (site.css § the tile), in a quieter register: `.sections` renders it flat on the page ground rather than filled, so a docs page showing the strip over a grid of guides never reads as eight tiles of one kind. What it says is the other half of that distinction — the strip carries a live COUNT per section, the grid below carries the section's own things. Counts, not prose, because this row repeats the header's nav on every page and has to say something the header cannot: how much is solved, how much is written, whether the shell is up. Four sentences repeated five times say nothing. Two switches, and they are independent: `subject` — signed out the tiles are the same boxes with the same copy, inert, wearing a padlock where the arrow goes. The visitor should see what is behind the login. `sections` — the live counts (`content.section_state`). The auth tier renders this strip too and has no clone to count, so where it is absent every tile falls back to its prose line. Never invent a number that would drift.

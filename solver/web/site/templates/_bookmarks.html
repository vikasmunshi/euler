{# The bookmarks menu (web-server-guide § The site): the header's third icon control, after back and refresh. Back and refresh move you inside the pane; this one is the mark that moves you OFF the site, and it sits with them because all three are navigation rather than state. Everything in it is off-site, and that is what makes it a menu instead of more nav items: the primary nav names pages this app renders, and a row that mixed in projecteuler.net would be claiming a page it cannot serve. The list is static chrome — the same for every collaborator, no request state in it — so it is markup here rather than context, exactly like the footer's documents. Every link wears the `.ext` marker (↗) and site.js's externalize() gives it target=_blank + rel=noopener: an off-site click opens a tab and leaves both panes alone, so the terminal — the one thing the app promises never to drop — is never navigated away from by following a bookmark. Live signed out as well as in. An external link needs no session, and a visitor who is not being let in yet can still be pointed at the problems and the source; it is the third control, with the brand and the user pill, that is not dimmed out there. #}

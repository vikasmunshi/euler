Problem 1: Multiples of 3 or 5

If we list all the natural numbers below 10 that are multiples of 3 or 5, we get 3, 5, 6 and 9. The sum of these multiples is 23. Find the sum of all the multiples of 3 or 5 below 1,000.

Crossing out: the sieve

Crossing out, from 2 to two million
Dividing each number by everything up to its square root

Press Space for each step: 2, 3, 5 and 7 cross out their multiples, then the survivors light up. The last step races both methods below two million, live on this laptop. ← steps back; R replays the current step.

Below two million: 4,347,776 cross-outs against 179,492,731 divisions, about 41× less work. In Python it's 0.3 s against 19 s.

The point for a general audience: we found primes without ever dividing. Doing the work in a smarter order beats doing it faster.

Problem 15, solved by hand in 2019, before any AI

    
Its explanation, written later together with AI

    
@runner.main
def solve(*args: str) -> str:
    lattice_size = runner.parse_int(args[0])
    return str(math.factorial(2 * lattice_size)
               // math.factorial(lattice_size) ** 2)

    
“The crucial observation is that the geometry of the grid is irrelevant to the count: any valid path consists of exactly 2n unit steps, of which n must go right and n must go down. A path is fully determined by the order in which we interleave these two kinds of moves.”
